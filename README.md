# AI-ASSIST
# AI-Powered Learning Assistant

An AI-driven educational platform that analyzes student knowledge, generates personalized study plans, and provides interactive tutoring.

## Features (MVP)
* Student Registration & Profiling
* LLM-powered Diagnostic Assessments
* Personalized Study Plan Generation

## Tech Stack
* **Backend:** FastAPI (Python)
* **AI Integration:** LangChain, LLM APIs
* **Database:** PostgreSQL
